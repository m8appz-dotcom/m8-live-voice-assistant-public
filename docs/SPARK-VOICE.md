# Private English voice pathway

The default bridge provider is `spark`. The existing authenticated `/gemini` WebSocket path remains a compatibility transport for the original client; it does not send the Spark session to Google. Set `M8LIVE_PROVIDER=gemini` explicitly only for an intentional legacy rollback.

`server/spark-voice.mjs` connects three existing server-configured APIs. It streams text from an OpenAI-compatible chat-completions endpoint, starts speech on complete short sentences/phrases while later tokens are still arriving, and forwards native 22,050 Hz PCM from the prepared Magpie service using its English Aria voice. The microphone path accepts bounded 16 kHz PCM, detects speech and a 400 ms pause, and uses authenticated NeMo transcription. An explicitly configured `SPARK_ASR_KIND=whisper` supports the existing raw-WAV transcription contract as an alternative; there is no silent provider fallback.

The selected local combination was measured against the existing compatibility LLM route, Kokoro speech, and CPU transcription. These are small development samples, not production latency guarantees or a universal optimum. Machine tests exercised the real services; unit tests use controlled responses and do not stand in for those service calls.

## Server configuration

Configure SPARK_LLM_URL, SPARK_LLM_MODEL, SPARK_ASR_URL, SPARK_ASR_KIND, SPARK_ASR_MODEL, SPARK_TTS_URL and SPARK_TTS_TOKEN on the server only. The ASR model must be one actually exposed by the configured service. The current native speech contract uses Aria, en-US and 22,050 Hz PCM. Use stable HTTPS service origins or an authenticated private connection exposed on loopback. Remote plaintext URLs, credentials in URLs and query-string credentials are rejected. No private host, model ID or service credential is included in this repository.

The bridge and demo authenticate separately. The browser signs in with a passkey; the demo server uses its scoped bridge identity to contact the private voice relay. The relay supplies the speech identity to the inference services. A machine acceptance identity is not a human passkey and never substitutes for holder enrollment.

## Bounded operation

Only plain user text and PCM input are accepted. The server fixes the English instruction and voice. Client-supplied tools, system prompts, model IDs, media URLs and account actions are not executed. Sessions last at most three minutes, allow at most twelve questions, cap incoming frames and total bytes, and keep only a short in-memory conversation history. Closing or interrupting a session aborts outstanding requests. Transcription, model and speech requests have deadlines. Raw upstream errors and credentials are not returned to the browser.

The isolated run disables notification and OpenClaw integrations. It uses a separate local state directory and existing inference APIs; it neither starts nor changes a remote service or production database. Scope the service identities and protect the private environment when deploying. The original hosted browser app uses this isolated pathway; unrelated services and production databases remain outside its scope.

## SDK 58 and native source

The app uses Expo 58, React Native 0.88, maintained Expo Audio playback and Audio Studio. It requests required native peers directly and uses a patched, narrowly scoped minimatch override for Expo fingerprinting. Node 24.x or 26.x is required. The bridge reports which sign-in methods are configured; the client does not show an unavailable password action.

Android is an existing manually maintained project with custom Android Auto and device-control code. It is not regenerated by Prebuild. Its installed package identity is retained as `com.m8apps.m8live`; app.json now matches that existing native identity. The Gradle wrapper follows the installed React Native Gradle plugin, and existing image resources remain unchanged.

The generic Expo warning about automatically syncing Prebuild fields is disabled for this explicitly manual Android workflow. It is replaced by `tests/native-config.test.mjs`, which checks native identity/version, declared permission parity, preservation of custom service registration and Gradle toolchain parity. Do not run `prebuild --clean` over these custom sources. Future native configuration changes must update the tracked Android project explicitly.

Validation covers TypeScript, SDK compatibility, dependency audit, native configuration checks, voice/authentication regressions and the actual exported web client. The Gradle 9.4.1 / Java 17 toolchain was exercised. A full Android APK/iOS build and physical device playback are not claimed; this isolated X environment has no configured Android SDK. The holder completed real passkey sign-in and confirmed English microphone recognition and audible playback in the hosted browser on 22 November 2026. Native device acceptance and optional second-key recovery remain unverified; those checks do not block the already verified browser demonstration. Existing authentication and recovery methods are preserved.

Review regressions also cover cancellation while a later utterance ends, duration-based native playback deadlines, and the Android Auto PCM rate contract. The car client applies both the negotiated setup rate and each PCM MIME rate through AudioTrack's source playback rate. The pure Kotlin parser's JVM check is documented in `tests/native/README.md`; it covers Spark, legacy fallback and invalid-rate rejection. This check does not compile Android framework bindings or establish physical in-car playback.

## Rollback

Keep the pre-migration feature commit and recovery refs. Restore the pre-migration package/lock/source as one unit and reinstall its pinned dependencies if reversing the SDK change. The isolated relay can be stopped without changing the remote inference services. Preserve local workspace exports and the ignored state directory before removing a development copy.
